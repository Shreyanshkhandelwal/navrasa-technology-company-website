# Founder portraits

Drop background-removed portraits here, then set `photo` in `src/data/site.ts`:

    photo: "/team/shreyansh.png"
    photo: "/team/sargam.png"

Guidelines
- Transparent PNG (subject cut out), ~900x1100px, subject centred and bottom-aligned.
- Shot against a plain background; the card supplies its own organic backdrop.
- Keep each file under ~300 KB. If no photo is set, a monogram placeholder is shown.
